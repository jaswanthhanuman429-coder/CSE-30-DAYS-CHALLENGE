
This is my second challenge in the 30 Days C Programming Challenge.
In this challenge, I created a simple Fuel Cost Calculator using C.
The program takes distance, mileage, and fuel price as input.
It calculates how much fuel is required for the journey.
It then calculates the total cost of the required fuel.
This project helped me practice variables, input/output, and arithmetic operations.
I also learned how to work with floating-point values in C.
Overall, it is a simple project to strengthen my C programming basics.
